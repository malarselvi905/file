# Secure File Vault – Academic Security Testing Checklist

| Test ID | Security Domain | Test Description | Input / Vector | Expected Result | Actual Result | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-SEC-01** | Authentication | Password Complexity Validation | Weak password `123` during registration | Registration rejected; enforces 8+ chars with uppercase, lowercase, digit, and symbol. | Form highlights error; password not saved. | **PASSED** |
| **TC-SEC-02** | Authentication | Password Hashing Verification | Plaintext password `User@Vault2026!` | Password hashed with Werkzeug PBKDF2/SHA256 (600,000 rounds) or scrypt. No plaintext stored. | Database column `password_hash` stores salt + hash only. | **PASSED** |
| **TC-SEC-03** | Authentication | Invalid Credentials Handling | Incorrect password 3 times | Login failed; generic "Invalid username or password" message; event logged. | Failure logged in `login_attempts` table. | **PASSED** |
| **TC-SEC-04** | Authentication | Account Lockout Protection | 5 consecutive incorrect passwords | Account locked for 15 minutes; `locked_until` timestamp set; audit alert generated. | Account locks immediately; subsequent attempts rejected with lockout notice. | **PASSED** |
| **TC-SEC-05** | Authorization | IDOR Prevention on Download | User Alice requests Bob's file via `/api/files/download/3` | System verifies `owner_id == session.user_id`; returns `403 Forbidden`. | Download blocked; `UNAUTHORIZED_ACCESS_ATTEMPT` audit log generated. | **PASSED** |
| **TC-SEC-06** | Authorization | Unauthenticated File Access | Direct GET `/api/files/download/1` without session | Redirects to login or returns `401 Unauthorized`. | Access denied; zero data exposed. | **PASSED** |
| **TC-SEC-07** | Authorization | Admin Route Protection | Standard user visits `/admin` or `/api/admin/users` | System checks `user.role == 'admin'`; blocks non-admin users. | Returns `403 Forbidden` with unauthorized access alert. | **PASSED** |
| **TC-SEC-08** | File Upload | Malicious Executable Block | Uploading `exploit.php` or `payload.exe` | Upload rejected; extension validator detects prohibited extension. | Rejected with HTTP 400 and security notification. | **PASSED** |
| **TC-SEC-09** | File Upload | Path Traversal Prevention | Uploading filename `../../../../etc/passwd` | Filename sanitized to `passwd` and stored under UUID like `vault_1f2e3d...enc`. | File stored in designated private vault with clean UUID; traversal neutralized. | **PASSED** |
| **TC-SEC-10** | File Upload | Oversized File Rejection | Uploading file exceeding 15MB limit | System rejects payload with HTTP 413 "File Too Large". | Upload intercepted before storage exhaustion. | **PASSED** |
| **TC-SEC-11** | Cryptography | Encryption at Rest (AES-256-GCM) | User uploads `confidential_report.pdf` | File encrypted with unique 12-byte IV and AES-256-GCM before writing to disk. | Stored binary on disk is unintelligible ciphertext; original not on disk. | **PASSED** |
| **TC-SEC-12** | Cryptography | Authenticated Decryption & Integrity | User requests authorized download | System loads ciphertext + IV + tag, validates GCM auth tag and SHA-256 digest. | Exact original file restored and sent with secure streaming headers. | **PASSED** |
| **TC-SEC-13** | Cryptography | Ciphertext Tampering Detection | Modifying 1 byte of encrypted file on disk | Decryption fails due to GCM authentication tag mismatch (`InvalidTag`). | Decryption halted; `CORRUPTED` status logged; tamper alert triggered. | **PASSED** |
| **TC-SEC-14** | Injection | SQL Injection Resistance | Login username `' OR '1'='1' --` | Parameterized ORM query safely binds input as literal string; injection fails. | Attack neutralized; invalid credentials logged. | **PASSED** |
| **TC-SEC-15** | Injection | Cross-Site Scripting (XSS) Prevention | File name `<script>alert(1)</script>.pdf` | Filename HTML-escaped and sanitized upon rendering. | Rendered as text; zero script execution in browser DOM. | **PASSED** |
| **TC-SEC-16** | Auditing | Audit Trail Completeness | User Alice uploads and deletes a file | Separate entries created in `audit_logs` for `FILE_UPLOAD_ENCRYPTED` and `FILE_DELETED`. | Timestamp, user ID, IP address, and status accurately captured in database. | **PASSED** |
| **TC-SEC-17** | Session | Inactivity Session Expiration | User inactive for configured session limit | Session invalidated; subsequent requests prompt re-authentication. | Session cleared safely; sensitive screens locked. | **PASSED** |
